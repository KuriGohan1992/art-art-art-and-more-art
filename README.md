# Art, art, art, and more art!

This project is my digital portfolio for **GEARTS (Art Appreciation)**. It brings together the artworks, activities, creative explorations, and reflections I created throughout the course.

The website itself is also part of how I wanted to present the portfolio: a colorful, moving collage of different art forms, paired with the works and experiences I collected throughout the semester.

Built with **Vue 3 + Vite**.

## Install

```bash
npm install
npm run dev
```
